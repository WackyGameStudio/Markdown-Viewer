# 📝 Markdown Viewer

AI를 활용하며 로컬에 생성되는 수많은 마크다운(MD) 파일들을 VS Code와 같은 무거운 IDE에서 일일이 확인하는 번거로움을 해결하기 위해 탄생한 전용 뷰어입니다. 마크다운 파일이 포함된 폴더를 열기만 하면 즉시 쾌적하게 내용을 확인하고 탐색할 수 있습니다.

## 🎯 프로젝트 목표
*   **가벼움 & 신속함**: IDE를 실행하지 않고도 폴더 내 수많은 마크다운 문서를 빠르게 브라우징합니다.
*   **집중된 사용자 경험**: 마크다운 감상에 최적화된 UI와 내비게이션 기능을 제공합니다.


## ✨ 주요 기능

### 📂 폴더 및 파일 관리
*   **루트 폴더 탐색**: 로컬 시스템의 폴더를 선택하여 포함된 모든 마크다운 파일을 트리 구조로 확인합니다.
*   **최근 폴더 (Recent Folders)**: 최근에 열었던 폴더 5개를 기억하여 빠르게 다시 열 수 있습니다.
*   **폴더 북마크 (Bookmarks)**: 자주 보는 폴더를 북마크에 등록하여 언제든 즉시 접근합니다.
*   **자동 복원**: 앱 실행 시 마지막으로 열려있던 유효한 폴더를 자동으로 오픈합니다.
*   **사이드바 확장 애니메이션**: 사이드바 호버 시 패널이 우측으로 슬라이딩 확장되어 긴 파일명도 쉽게 읽을 수 있습니다. (`...` 줄임표와 조건부 툴팁 지원)

### 📖 마크다운 렌더링 & UX
*   **고성능 렌더링**: `react-markdown`과 GFM 플러그인을 사용하여 코드 하이라이팅, 테이블 등 다양한 마크다운 문법을 완벽하게 지원합니다.
*   **실시간 목차 (TOC)**: 문서의 헤더 구조를 분석하여 우측 사이드바에 실시간으로 목차를 생성하고, 클릭 시 해당 위치로 부드럽게 이동합니다.
*   **뷰포트 너비 조절**: 툴바의 슬라이더를 이용해 문서 뷰어의 최대 너비를 실시간으로 조정할 수 있습니다. (설정값은 자동 저장됩니다.)

### 🚀 내비게이션 및 히스토리
*   **세션 기반 스크롤 위치 복원**: 문서 이동 시 보던 위치를 기억합니다. `useLayoutEffect`를 통해 페이지 로드 직후 찰나의 순간에 복원되므로 렉 없는 즉각적인 내비게이션이 가능합니다. (폴더 전환 시 초기화)
*   **마우스 앞/뒤 버튼 지원**: 웹 브라우저처럼 마우스 엄지 버튼을 눌러 이전/다음 문서로 빠르게 이동할 수 있습니다.
*   **스마트 링크 핸들링**: 
    *   문서 내 로컬 `.md` 파일 링크 클릭 시 앱 내에서 즉시 이동.
    *   웹 링크(`http/https`)는 시스템 기본 브라우저로 오픈하여 앱 상태를 보호합니다.

## 🛠 Tech Stack
*   **Backend**: Go, [Wails v2](https://wails.io/)
*   **Frontend**: React, TypeScript, Vite
*   **Styling**: Vanilla CSS (Custom Variable 기반 테마 시스템)
*   **Markdown**: react-markdown, remark-gfm, rehype-highlight
*   **Icons**: Lucide-React

## 🚀 시작하기

### 개발 모드 실행
```bash
wails dev
```

### 배포 빌드 (Windows)
```bash
wails build
```
